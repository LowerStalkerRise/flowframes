# Flowframes

### AI-powered video frame interpolation

Flowframes uses state-of-the-art AI models to increase the frame rate of any video. Convert 24fps footage to buttery-smooth 60, 120, or even 240fps using DAIN, RIFE, and other interpolation networks.

<br>

---

## Features

| | |
|:---|:---|
| **Multiple AI Engines** | Supports RIFE, DAIN, FLAVR, and other cutting-edge interpolation models |
| **Any Frame Rate** | Target 30, 60, 120, or 240fps — or any custom multiplier you need |
| **GPU Accelerated** | NVIDIA CUDA and AMD support for real-time preview and fast encoding |
| **Batch Processing** | Queue multiple videos and process them overnight automatically |
